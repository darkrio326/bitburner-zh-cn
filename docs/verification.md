日期：2026-11-25（Asia/Shanghai）。目标：Bitburner v3.0.1，固定提交 `3162fd2590e221eadd0c0fbd46151913f7c4c41c`。

本轮修复截图中的安装强化结果弹窗，并保留 v0.8.0 的 410 条高级玩法补译。

## 原因与修复

`AugmentationHelpers.ts` 将安装说明、强化名单与结尾拼成单个多行字符串；`DialogBox.tsx` 将其渲染为保留换行的 React Text 节点。随后 `installAugmentations()` 执行重置并跳转到 Terminal，结果弹窗继续显示。旧版词库没有完整结果模板，页面作用域也已不再是强化页，故直接模式与悬停模式均漏掉这段文本。

新增仅用于弹窗的已审校完整消息匹配；安装名单槽位只接受已知强化名称及 NeuroFlux Governor 的整数等级。名单、排序、等级、换行与 React 节点原样保留。公司/派系工作、移植结果和 Source-File 获得弹窗根据自身内容识别，不再依赖下层页面。Source-File 说明复用原有译文。
